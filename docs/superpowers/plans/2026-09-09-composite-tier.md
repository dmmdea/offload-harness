# Composite Tier (0.116.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the Qube one installed tier (`blackwell-3x16`) that *composes* `blackwell-16` and `blackwell-2x16` as three device layers (single / pair / triple), decide per task which layer serves it, record that decision on every result, advertise the layers to the fleet, and ship it as 0.116.0 with four live gates on the Qube.

**Architecture:** The tier table (`setup/templates/profiles.json`) declares `composes` + `layers`; `tierseed` seeds `tier_profile`, `tiers` and `layers` into `config.json`, so at runtime everything reads config (a box that seeds none has one implicit layer and is byte-identical). A new pure package `internal/placement` turns (task class, token need, quality gate, `context_class`, live occupancy, live guards) into a `Decision {tier, layer, role, seat, devices, reason}`; the delegate runner, the agent-contract pipeline, the MCP `agent_run`/`agent_delegate` doors, the fleet node health and the cascade all consume it and publish it under the key `placed`. Guards for the display card (free-VRAM floor read live from nvidia-smi, operator presence read live from the Windows last-input tick) live in `internal/placement` with small helper packages.

**Tech Stack:** Go 1.26 (stdlib + `golang.org/x/sys/windows` already in go.mod), llama-swap YAML templates, PowerShell installer, Markdown docs generated by `cmd/gentiers`.

**Spec:** `docs/superpowers/specs/2026-09-09-qube-composite-tier-design.md` (APPROVED 2026-09-09). Read it first. Three reshapes against the spec are recorded in ADR 0039 (Task 12) and must be applied as written here:

1. **Window overflow escalates to the PAIR layer's long seat** (`qwen3.8-27b-262k`, 262,144 window, prefill 1,197 t/s on the 5060 Ti pair); the **triple** layer's `qwen3.8-flash-next-262k` (prefill 69 t/s: a 200k prompt takes ~48 min against a 900 s contract cap) is entered on an explicit `context_class: "long"` only, under the display-floor and presence guards. Spec D2/D4 said "triple on window overflow"; that cannot finish inside any contract budget, measured.
2. **Seat roles live inside layers** (`layers[].seats[].role` = agent | long | router | ocr | vision | stt | big) instead of the spec's two flat keys `agent_long_model` / `agent_overflow_model`: the pair has TWO agent-class seats (agent + long) and flat keys cannot express it.
3. **The placement block is published as `placed`**, not `placement`: `placement` is already the placement-REASON string on every `agent_delegate` row (`internal/delegate/wire.go:93`), read by `fleet_smoke_cmd.go` and documented; retyping it would break every scripted reader.

Also carried from the live-box physics read (ledger NIGHTSHIFT 6, 2026-09-09 ~20:1x): the live llama-swap matrix makes every interactive seat, the vLLM pair seat included, mutually exclusive on cards 0 and 2, and the pair seat pins its KV pool from all free memory minus 0.5 GiB. So the single layer's overflow seat is only *admissible* when it is already loaded or a single-layer device has ≥ its footprint free — the placement package must read that live and say so; it must never assume the single layer is free. The guarded display-card overflow (e2b/e4b under the floor when the operator is away) is SURFACED to the operator (Task 13 report), not built.

```go
package config

import (
	"fmt"
	"strings"
	"time"
)

// LayerSeat is one ROLE a layer serves: which llama-swap model answers it, the
// window it was measured at, the VRAM it needs on EACH device of the layer's
// set (so admissibility beside a resident can be computed from a live
// nvidia-smi read), and — for a vLLM seat — the in-flight count at which the
// seat is saturated (its max_num_seqs). The role "router" has no model: the
// cascade's entry-tier router picks the rung.
type LayerSeat struct {
	Role         string  `json:"role"`
	Model        string  `json:"model,omitempty"`
	CtxTokens    int     `json:"ctx_tokens,omitempty"`
	FootprintGiB float64 `json:"footprint_gib,omitempty"`
	MaxInflight  int     `json:"max_inflight,omitempty"`
}

// LayerSpec is one DEVICE SET of a composite box and the tier that device set
// IS. Devices are CUDA_VISIBLE_DEVICES strings under CUDA_DEVICE_ORDER=PCI_BUS_ID
// — the same ordering the tier's gpu_env pins use — and each entry is one
// alternative set the layer may occupy: ["0","2"] means "one card, 0 or 2";
// ["0,2"] means "the pair". Guards name the live checks an opt-in layer must
// pass at admission: "display_floor" (DisplayDevice must have ≥ DisplayFloorGiB
// free) and "presence" (the operator must be away from the desk).
type LayerSpec struct {
	Name            string      `json:"name"`
	Tier            string      `json:"tier"`
	Devices         []string    `json:"devices"`
	Seats           []LayerSeat `json:"seats"`
	OptIn           bool        `json:"opt_in,omitempty"`
	DisplayDevice   string      `json:"display_device,omitempty"`
	DisplayFloorGiB float64     `json:"display_floor_gib,omitempty"`
	Guards          []string    `json:"guards,omitempty"`
}

// layerGuards is the closed guard vocabulary; anything else is a typo that
// would otherwise silently guard nothing.
var layerGuards = map[string]bool{"display_floor": true, "presence": true}

// presenceModes is the closed vocabulary of operator_presence.
var presenceModes = map[string]bool{"": true, "auto": true, "away": true, "present": true}

// Composite reports whether this box declares layers — the ONLY switch every
// composite code path keys on, so a box that seeds none stays byte-identical.
func (c Config) Composite() bool { return len(c.Layers) > 0 }

// Layer looks a layer up by name.
func (c Config) Layer(name string) (LayerSpec, bool) {
	for _, l := range c.Layers {
		if l.Name == name {
			return l, true
		}
	}
	return LayerSpec{}, false
}

// LayerSeat resolves the seat serving `role` on `layer`; ok=false when either
// is undeclared. Callers treat ok=false as "that path does not exist on this
// box", never as an error.
func (c Config) LayerSeat(layer, role string) (LayerSeat, bool) {
	l, ok := c.Layer(layer)
	if !ok {
		return LayerSeat{}, false
	}
	for _, s := range l.Seats {
		if s.Role == role {
			return s, true
		}
	}
	return LayerSeat{}, false
}

// PresenceMode is operator_presence with its default: "auto" reads the
// machine; "away"/"present" are operator overrides for a known window.
func (c Config) PresenceMode() string {
	if m := strings.TrimSpace(c.OperatorPresence); m != "" {
		return m
	}
	return "auto"
}

// OperatorIdle is how long the desk must be untouched before "auto" reads as
// away. Default 15 minutes: long enough that a coffee break does not admit a
// three-card engine onto the display card.
func (c Config) OperatorIdle() time.Duration {
	if c.OperatorIdleSec > 0 {
		return time.Duration(c.OperatorIdleSec) * time.Second
	}
	return 15 * time.Minute
}

// ValidateLayers refuses the declaration shapes that would misplace work:
// a duplicate layer or role (ambiguous lookup), a layer with no devices
// (nothing to pin), a modelled role without a model, an unknown guard, a
// floor without a device to read, a presence mode outside the vocabulary,
// and a tiers list that does not include the installed profile. A config
// with no layers always validates.
func (c Config) ValidateLayers() error {
	if !presenceModes[strings.TrimSpace(c.OperatorPresence)] {
		return fmt.Errorf("config: operator_presence %q is not one of auto|away|present", c.OperatorPresence)
	}
	if !c.Composite() {
		return nil
	}
	if c.TierProfile != "" {
		found := false
		for _, t := range c.Tiers {
			if t == c.TierProfile {
				found = true
			}
		}
		if !found {
			return fmt.Errorf("config: tiers must include tier_profile %q", c.TierProfile)
		}
	}
	names := map[string]bool{}
	for _, l := range c.Layers {
		if l.Name == "" {
			return fmt.Errorf("config: a layer has no name")
		}
		if names[l.Name] {
			return fmt.Errorf("config: duplicate layer %q", l.Name)
		}
		names[l.Name] = true
		if len(l.Devices) == 0 {
			return fmt.Errorf("config: layer %q declares no devices", l.Name)
		}
		roles := map[string]bool{}
		for _, s := range l.Seats {
			if s.Role == "" {
				return fmt.Errorf("config: layer %q has a seat with no role", l.Name)
			}
			if roles[s.Role] {
				return fmt.Errorf("config: layer %q declares duplicate role %q", l.Name, s.Role)
			}
			roles[s.Role] = true
			if s.Role != "router" && s.Model == "" {
				return fmt.Errorf("config: layer %q role %s needs a model", l.Name, s.Role)
			}
		}
		for _, g := range l.Guards {
			if !layerGuards[g] {
				return fmt.Errorf("config: layer %q names unknown guard %q", l.Name, g)
			}
		}
		if l.DisplayFloorGiB > 0 && l.DisplayDevice == "" {
			return fmt.Errorf("config: layer %q display_floor_gib needs display_device", l.Name)
		}
	}
	return nil
}
```

```go
// Package placement answers ONE question for every unit of work on a composite
// box: which layer. It is pure — every live fact (seat occupancy, free VRAM,
// operator presence) is handed in through Live so the table is exhaustively
// testable and the readers are swappable. See ADR 0039 and
// docs/systems/composite-tier.md for the table in prose.
package placement

import (
	"fmt"
	"strings"

	"github.com/dmmdea/offload-harness/internal/config"
	"github.com/dmmdea/offload-harness/internal/core"

// (types as in Interfaces above, each with a doc comment)

func seat(layers []config.LayerSpec, layer, role string) (config.LayerSpec, config.LayerSeat, bool) {
	for _, l := range layers {
		if l.Name != layer {
			continue
		}
		for _, s := range l.Seats {
			if s.Role == role {
				return l, s, true
			}
		}
	}
	return config.LayerSpec{}, config.LayerSeat{}, false
}

func placed(l config.LayerSpec, s config.LayerSeat, devices []string, reason string) core.Placed {
	return core.Placed{Tier: l.Tier, Layer: l.Name, Role: s.Role, Seat: s.Model, Devices: devices, CtxTokens: s.CtxTokens, Reason: reason}
}

// Decide implements the table. Rows, in order:
//   mechanical → single/router. ocr → single/ocr. vision → pair/vision. media → pair.
//   agent, context_class long → triple/long under the guards (defer naming the guard).
//   agent, need ≤ pair agent window → pair/agent; saturated + quality-gated → wait;
//     saturated + best-effort → single/agent when admissible, else wait.
//   agent, need > pair window → pair/long when it fits; else triple/long under the
//     guards; else defer (contract too big for every window).
func Decide(req Request, layers []config.LayerSpec, live Live) Decision {
	if len(layers) == 0 {
		return Decision{}
	}
	switch req.Class {
	case ClassMechanical:
		if l, s, ok := seat(layers, "single", "router"); ok {
			return Decision{Placed: placed(l, s, l.Devices, "mechanical text → single layer, the entry-tier router picks the rung")}
		}
	case ClassOCR:
		if l, s, ok := seat(layers, "single", "ocr"); ok {
			return Decision{Placed: placed(l, s, l.Devices, "ocr role → single layer")}
		}
	case ClassVision:
		if l, s, ok := seat(layers, "pair", "vision"); ok {
			return Decision{Placed: placed(l, s, l.Devices, "vision role → pair layer")}
		}
	case ClassMedia:
		if l, ok := layerByName(layers, "pair"); ok {
			return Decision{Placed: core.Placed{Tier: l.Tier, Layer: l.Name, Role: "media", Devices: l.Devices, Reason: "media pools → pair layer"}}
		}
	case ClassAgent:
		return decideAgent(req, layers, live)
	}
	return Decision{}
}

func layerByName(layers []config.LayerSpec, name string) (config.LayerSpec, bool) {
	for _, l := range layers {
		if l.Name == name {
			return l, true
		}
	}
	return config.LayerSpec{}, false
}

func decideAgent(req Request, layers []config.LayerSpec, live Live) Decision {
	maxTok := req.MaxTokens
	if maxTok <= 0 {
		maxTok = 1024
	}
	need := req.EstTokens + maxTok
	if req.ContextClass == "long" {
		if l, s, ok := seat(layers, "triple", "long"); ok {
			return admitGuarded(l, s, live, fmt.Sprintf("context_class long → triple layer (%s, window %d)", s.Model, s.CtxTokens))
		}
	}
	pl, pa, hasPair := seat(layers, "pair", "agent")
	if hasPair && need <= pa.CtxTokens {
		st := readSeat(live, "pair", "agent")
		saturated := st.Known && st.Loaded && pa.MaxInflight > 0 && st.Inflight >= pa.MaxInflight
		base := fmt.Sprintf("fits the pair window (need ~%d ≤ %d)", need, pa.CtxTokens)
		if !saturated {
			return Decision{Placed: placed(pl, pa, pl.Devices, base)}
		}
		sat := fmt.Sprintf("pair saturated (%d in flight ≥ max_inflight %d)", st.Inflight, pa.MaxInflight)
		if req.QualityGated {
			return Decision{Placed: placed(pl, pa, pl.Devices, sat+"; quality-gated work waits for the pair"), Wait: true}
		}
		if sl, ss, ok := seat(layers, "single", "agent"); ok {
			if dev, why, adm := admissibleSingle(sl, ss, live); adm {
				return Decision{Placed: placed(sl, ss, []string{dev}, sat+"; best-effort overflow to the single layer: "+why)}
			} else {
				return Decision{Placed: placed(pl, pa, pl.Devices, sat+"; single layer not admissible ("+why+"); waits for the pair"), Wait: true}
			}
		}
		return Decision{Placed: placed(pl, pa, pl.Devices, sat+"; no single layer declared; waits for the pair"), Wait: true}
	}
	if ll, ls, ok := seat(layers, "pair", "long"); ok && need <= ls.CtxTokens {
		return Decision{Placed: placed(ll, ls, ll.Devices, fmt.Sprintf("window overflow: need ~%d > pair agent window %d; the pair's long seat holds it (%d)", need, pa.CtxTokens, ls.CtxTokens))}
	}
	if tl, ts, ok := seat(layers, "triple", "long"); ok && need <= ts.CtxTokens {
		return admitGuarded(tl, ts, live, fmt.Sprintf("window overflow: need ~%d exceeds every pair window; triple layer (%s, %d)", need, ts.Model, ts.CtxTokens))
	}
	largest := 0
	for _, l := range layers {
		for _, s := range l.Seats {
			if s.CtxTokens > largest {
				largest = s.CtxTokens
			}
		}
	}
	return Decision{Defer: true, DeferClass: core.DeferClassContract,
		Placed: core.Placed{Layer: "none", Reason: fmt.Sprintf("contract needs ~%d tokens; no layer window holds it (largest %d)", need, largest)}}
}

func readSeat(live Live, layer, role string) SeatState {
	if live.Seat == nil {
		return SeatState{}
	}
	return live.Seat(layer, role)
}

// admissibleSingle reports whether the single layer's agent seat can take work
// NOW: it is loaded, or one of the layer's single-card devices has at least the
// seat's footprint free. Beside a loaded pair seat on this hardware neither
// holds (≈0.8 GiB free per pair card), and the reason says so with the numbers.
func admissibleSingle(l config.LayerSpec, s config.LayerSeat, live Live) (device, why string, ok bool) {
	st := readSeat(live, l.Name, s.Role)
	if st.Known && st.Loaded {
		return firstDevice(l.Devices), fmt.Sprintf("%s already loaded (%d in flight)", s.Model, st.Inflight), true
	}
	if live.DeviceFree == nil {
		return "", "no VRAM reader on this box", false
	}
	maxFree := -1.0
	for _, d := range l.Devices {
		if strings.Contains(d, ",") {
			continue // a single layer's devices are single cards
		}
		free, known := live.DeviceFree(d)
		if !known {
			continue
		}
		if free >= s.FootprintGiB {
			return d, fmt.Sprintf("device %s has %.1f GiB free ≥ footprint %.1f", d, free, s.FootprintGiB), true
		}
		if free > maxFree {
			maxFree = free
		}
	}
	if maxFree < 0 {
		return "", "no single-layer device readable", false
	}
	return "", fmt.Sprintf("no single-layer device has ≥ %.1f GiB free (max %.1f)", s.FootprintGiB, maxFree), false
}

func firstDevice(devs []string) string {
	if len(devs) == 0 {
		return ""
	}
	return devs[0]
}

// admitGuarded runs the layer's guards in declared order; the FIRST refusal
// names itself in Placed.Guard and Placed.Reason — never a silent fall-back.
func admitGuarded(l config.LayerSpec, s config.LayerSeat, live Live, why string) Decision {
	readings := []string{}
	for _, g := range l.Guards {
		switch g {
		case "display_floor":
			if live.DeviceFree == nil {
				return refused(l, s, g, why+"; display card free VRAM unreadable (no reader)")
			}
			free, ok := live.DeviceFree(l.DisplayDevice)
			if !ok {
				return refused(l, s, g, fmt.Sprintf("%s; display card (device %s) free VRAM unreadable", why, l.DisplayDevice))
			}
			if free < l.DisplayFloorGiB {
				return refused(l, s, g, fmt.Sprintf("%s; display card (device %s) has %.1f GiB free < floor %.0f GiB", why, l.DisplayDevice, free, l.DisplayFloorGiB))
			}
			readings = append(readings, fmt.Sprintf("display card device %s %.1f GiB free ≥ floor %.0f", l.DisplayDevice, free, l.DisplayFloorGiB))
		case "presence":
			if live.Presence == nil {
				return refused(l, s, g, why+"; operator presence unknown (no reader)")
			}
			p := live.Presence()
			switch {
			case p.Mode == "present":
				return refused(l, s, g, why+"; operator_presence=present (operator override)")
			case p.Mode == "away":
				readings = append(readings, "operator_presence=away (operator override)")
			case !p.Known:
				return refused(l, s, g, why+"; operator presence unknown on this OS — refused (fails closed for the display card)")
			case !p.Away:
				return refused(l, s, g, fmt.Sprintf("%s; operator at the desk (idle %d s < threshold)", why, p.IdleSec))
			default:
				readings = append(readings, fmt.Sprintf("operator away (idle %d s)", p.IdleSec))
			}
		}
	}
	reason := why
	if len(readings) > 0 {
		reason += "; guards: " + strings.Join(readings, ", ")
	}
	return Decision{Placed: placed(l, s, l.Devices, reason)}
}

func refused(l config.LayerSpec, s config.LayerSeat, guard, reason string) Decision {
	p := placed(l, s, l.Devices, reason)
	p.Guard = guard
	return Decision{Placed: p, Defer: true, DeferClass: core.DeferClassCapacity}
}
```

```go
// "present" are trusted overrides; "auto" asks the OS (Windows: the last-input
```

```go
package placement

import (
	"time"
	"unsafe"

	"golang.org/x/sys/windows"
)

var (
	user32           = windows.NewLazySystemDLL("user32.dll")
	kernel32         = windows.NewLazySystemDLL("kernel32.dll")
	shell32          = windows.NewLazySystemDLL("shell32.dll")
	procLastInput    = user32.NewProc("GetLastInputInfo")
	procGetTickCount = kernel32.NewProc("GetTickCount")
	procQueryUserNS  = shell32.NewProc("SHQueryUserNotificationState")
)

type lastInputInfo struct {
	cbSize uint32
	dwTime uint32
}

// probeOS: idle = GetTickCount − LASTINPUTINFO.dwTime (both 32-bit ticks, so
// the subtraction wraps correctly); a fullscreen D3D app, a busy or a
// presentation state (SHQueryUserNotificationState 2/3/4) reads as present
// regardless of idle — that is the "a game takes the desk" case.
func probeOS(idle time.Duration) Presence {
	var lii lastInputInfo
	lii.cbSize = uint32(unsafe.Sizeof(lii))
	r, _, _ := procLastInput.Call(uintptr(unsafe.Pointer(&lii)))
	if r == 0 {
		return Presence{Mode: "auto", Known: false, Note: "GetLastInputInfo failed (not an interactive session?)"}
	}
	tick, _, _ := procGetTickCount.Call()
	idleMs := uint32(tick) - lii.dwTime
	p := Presence{Mode: "auto", Known: true, IdleSec: int(idleMs / 1000)}
	var state int32
	if ret, _, _ := procQueryUserNS.Call(uintptr(unsafe.Pointer(&state))); ret == 0 {
		switch state {
		case 2, 3, 4: // QUNS_BUSY, QUNS_RUNNING_D3D_FULL_SCREEN, QUNS_PRESENTATION_MODE
			p.Away = false
			p.Note = "fullscreen/busy application in the foreground"
			return p
		}
	}
	p.Away = time.Duration(idleMs)*time.Millisecond >= idle
	return p
}
```

```go
// LiveFromConfig wires the real readers: seat occupancy through llama-swap
// (seatload — stops at /running for a cold seat, never loads), free VRAM from a
// fresh nvidia-smi read, presence from the OS or the config override. Every
// reader is bounded (4 s seat probe, 5 s nvidia-smi) and any failure reads as
// unknown, which the table treats as "neither credited nor blamed" for
// occupancy and as a refusal for the display-card guards.
func LiveFromConfig(cfg config.Config) Live {
	client := &http.Client{Timeout: 4 * time.Second}
	return Live{
		Seat: func(layer, role string) SeatState {
			s, ok := cfg.LayerSeat(layer, role)
			if !ok || s.Model == "" {
				return SeatState{}
			}
			ctx, cancel := context.WithTimeout(context.Background(), 4*time.Second)
			defer cancel()
			rd, err := seatload.Inflight(ctx, client, cfg.Endpoint, s.Model)
			if err != nil || rd.Ambiguous {
				return SeatState{}
			}
			return SeatState{Known: true, Loaded: rd.Loaded, Inflight: rd.Inflight}
		},
		DeviceFree: func(device string) (float64, bool) {
			ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
			defer cancel()
			devs, err := gpufree.Read(ctx)
			if err != nil {
				return 0, false
			}
			return gpufree.FreeGiB(devs, device)
		},
		Presence: func() Presence { return ProbePresence(cfg.PresenceMode(), cfg.OperatorIdle()) },
	}
}
```
