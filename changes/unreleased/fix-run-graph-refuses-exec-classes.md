### Fixed - the run-graph door refuses a graph that holds a node class that executes caller-supplied code

- **What was wrong.** A graph is data, but a third-party ComfyUI node pack can ship a node class that runs one of its string inputs as Python: the `ModelTest` class of the `ComfyUI-Image-Filters` pack runs its `code` input through `exec()`. Once that pack is installed in the ComfyUI the door uses, any submitted graph holding a `ModelTest` node ran arbitrary Python on the node's host, with the ComfyUI process's rights. The runner's preflight refused only classes that are missing, and nothing refused one that is present and dangerous.
- **What it does.** `render/refused-node-classes.json` lists such classes by name (one row today, `ModelTest`; a row is added only for a class whose pack source was read and found to execute a caller-supplied input). `render/comfy-run-graph.mjs` reads the graph against it before it provisions anything or starts or contacts ComfyUI, and a template's converted graph right after conversion: a hit is the typed defer `NODE_CLASS_REFUSED` with the class as `ref` and a sentence naming the class, its pack and why, and saying to remove the node. A fleet node refuses the same graph at ack time with a `400` before a job, a temp file or a lease exists (`mediacap.CheckGraphNodeClasses`, a Go copy held to the file by the existing comparison test), and the image, video and music runners refuse a `--graph` file with the same check before they post it. The match is exact and case-sensitive (`class_type` of an API graph, `type` of a UI-format workflow node). The local door answers the defer with `defer_class: contract`, not a capacity "try later": retrying the same graph never helps. A table file that cannot be read refuses every graph.
- **Checks.** One case in `render/comfy-run-graph.test.mjs` (a `ModelTest` graph is refused before any satisfy, start or post, a template's converted graph too, and the same graph without it runs); the existing node-pack table comparison test now also holds the Go copy to the new file.
