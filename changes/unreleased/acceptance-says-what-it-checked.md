### Fixed - `acceptance` says what it checked: a bad config fails the gate, `--only` is scoped, and a run that exercised nothing is not READY

- **What was wrong.** `acceptance --render --config X` where X failed to load (or did not exist) still started every render child, and each child resolved its own config; the report could end READY. `acceptance --only music` failed on an unrelated missing route or a down model server, and on a node with no music route it printed READY ("every bound capability was exercised") with nothing run. The plain gate printed the same sentence after running only the lease and interpreter checks. A killed gate run left its `gate-config-<pid>.json` copy of the config beside the config for a day. `audit-yaml` printed a clean `OK` line when the device-pin rules never ran because no card table could be read. `audit-config` with no tier turned a failed GPU probe into the `cpu` tier.
- **What it does now.** A config that failed to load, or a named file that is missing, is a FAIL row named `config` and no render child is started. With `--only`, a missing media route is a failure only when a requested group uses it, every other missing route and the alias row are SKIP rows "out of scope", and a run where every requested group was skipped prints NOTHING EXERCISED and exits non-zero. The final line says what ran (rendered group count, or "no route was rendered (pass --render)"). A leftover gate config whose process is dead is removed at the next gate run whatever its age. `audit-yaml` words the verdict line "cards NOT checked: no card table" (exit status unchanged). `audit-config` refuses to guess a tier when no GPU was read and asks for `--tier`.
- **Checks.** Run on a real node: a config that does not parse, and one that is missing, each gave a FAIL `config` row and no render call; `--only music` kept its own failing route as FAIL and the others as SKIP; `--only stt` on a config with no stt seat printed NOTHING EXERCISED and exited 1; a dead-pid leftover was removed while a live-pid and a non-numeric leftover stayed. The existing `audit-yaml` and `audit-config` tests pass. The failed-card-table and failed-GPU-probe paths were not run on a real node without a card table.
