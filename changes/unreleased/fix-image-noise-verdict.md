### Fixed - a render that decodes to pure noise is a failed job, not a `rendered` one (and `--resume` no longer skips it)

- **Why.** `generate-image` (single and `--batch`, local and `--route remote`) called an image rendered when the file existed, was not empty and decoded, without looking at it. A fleet node's sd.cpp render produced pure decoded noise for 17 of 43 frames; every one came back `ok:true`, verdict `rendered`, and `--resume` then skipped them as done.
- **What it does.** Every picture a diffusion render commits is judged by one detector (`internal/imagegen/noise.go`): luma averaged over whole 16 px and 8 px cells, then the lag-1 correlation of neighbouring cells (horizontal and vertical pairs pooled). It is decoded noise when that is under 0.3 at 16 px and under 0.6 at 8 px. Measured on real files: the 17 noise frames scored at most 0.149 and 0.452, and 400 real renders (contact sheets and strips included) at least 0.578 and 0.721. A canvas with a side under 256 px, a file that does not decode, and a blank image are not judged.
- **Where.** Every batch row in every mode is `failed` with the correlations as its error, and the file is moved aside as `<out>.noise` so nothing is left at `out`. `--resume` and `--dry-run --resume` do not take a noise file for finished, so a rerun renders it again and repairs noise files an earlier run left behind. A node's file is judged before it lands, so it never replaces a good file at `out`; the call ends as an `abstention` defer (not `infrastructure`: the node is not marked broken, and the job is not sent again). A single generate, generative edit or inpaint call defers the same way and records no success. Upscale, deterministic `edit-image` and run-graph outputs are not judged.
- **Check.** The detector was run over the two real sample files (noise judged noise, clean not) and over every file of the 17-frame noise set (all 17 noise) and of 44 clean frames (none).
- **Docs.** `docs/systems/media-generation.md` ("A picture of noise is not a render").
