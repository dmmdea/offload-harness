### Fixed - the selftest no longer shares child ports with the live stack, and its rows say what they measured

- **What was wrong.** `setup/selftest.ps1` started its transient llama-swap on the installed yaml, so its model children were numbered from the same start port as the live stack's llama-swap and could take or block the same ports. Its port check read the `State` column of `Get-NetTCPConnection`, which on Windows 11 build 26300 missed a live listener in 19 of 20 reads and never sees a server inside WSL. A tier whose second (warm) request failed or timed out still got a pass row with no rate. A tier that ran at a tenth of the speed of the same box's earlier pass still passed, because only a rate below 8 tok/s warned, and the receipt recorded no card memory. `proves[]` was a fixed list, so a pass with warn or fail rows still claimed what those rows did not prove. A q8_0 probe that never ran was written as a negative result, and a failed eviction cycle or a missing temp config could still read as a pass or fail of something that never ran.
- **What it does now.** The selftest runs its swap on a per-run copy of the yaml with `startPort: 18820`, probes every port of that span first and stops naming the busy one. The port check is a loopback connect plus a bind attempt. A failed warm request is a warn row (fail for an allocation or device-lost error) with the reason, and a tier below 60 % of the best rate in the newest five earlier receipts of the same box (same gpu, driver, backend) is a warn row that names that receipt. The receipt gains `card_mem_at_tier_start` (per-card memory in use when the tier rows start, from `nvidia-smi`) and `baseline`. `proves[]` is built from the final row statuses. The ctx and larger-ctx probes first unload the swap's models; a probe that did not run leaves `measured_ctx_ok` null. A failed q8_0 warm decode beside a working f16 is a fail, an eviction cycle that did not complete is a warn, and the whisper and vision rows are skipped when no temp config was written.
- **Checks.** Both PowerShell parsers read the script with no errors. The new port, yaml and receipt helpers were run on real input under Windows PowerShell 5.1 and PowerShell 7: a held port reads busy and a freed one free, the start-port line is inserted above `models:` or replaced, the port-model count matches the installer's on every Windows template, the card-memory snapshot reads the cards, and the baseline picks the best earlier pass. The selftest itself was not run.
