### Added - ComfyUI-RMBG and ComfyUI-Image-Filters are admitted to the run-graph node-pack allowlist

- **What was missing.** A scene-swap pipeline cuts a product out with the BiRefNet-HR model of `ComfyUI-RMBG` and transfers detail with the `RestoreDetail` node of `ComfyUI-Image-Filters`. A run-graph manifest could not name either pack: `render/node-packs.json` and its Go copy listed only VideoHelperSuite, MultiGPU (upstream and mirror) and GGUF, so a node refused the manifest with `NODE_PACK_NOT_ALLOWED` before any clone.
- **What it does.** Two rows are appended to `render/node-packs.json` and to `allowedNodePacks` in `internal/mediacap/nodepacks.go`, RMBG first, in the same order in both. The pack sources were read first. RMBG (read at commit `a66a5e6`) only creates folders under `models/` at import: no network call, subprocess or `eval`, and no `install.py`. One hazard is documented, not removed: its `BiRefNetRMBG` node, when the model files are missing from `models/RMBG/BiRefNet/`, downloads them from the pack author's Hugging Face repository at its newest revision and runs the downloaded Python files. A node that will run this pack must therefore have `BiRefNet-HR.safetensors`, `birefnet.py`, `BiRefNet_config.py` and `config.json` in `models/RMBG/BiRefNet/` beforehand; with them present the node never fetches. Image-Filters (read at commit `bbb3fb0`) ships a `ModelTest` node that runs a graph-supplied string through `exec()`. The harness already refuses that class by name (`NODE_CLASS_REFUSED`, `render/refused-node-classes.json`), which is the condition for admitting the pack; the rest of the pack imports cleanly. The review is written up in `docs/flows/run-graph-manifest-satisfaction.md` (step 1a), and `docs/FLEET-NODE.md` lists the two packs.
- **Checks.** `TestNodePackRowsMatchTheRunnersFile` (the two tables agree row by row), `node --test render/node-packs.test.mjs`, `go build ./...`, `go vet ./internal/mediacap/` and `go run ./cmd/changelog check`.
